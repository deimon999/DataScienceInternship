# CodTech IT Solutions Internship Project

## 📋 Project Overview

This repository contains deliverables from the **8-week Data Science, Web Development, and Optimization Internship** at **CodTech IT Solutions** (April 1 - May 2, 2026).

The internship now includes five major projects spanning:
- **ETL / Data Engineering** (Task 1)
- **Deep Learning** (Task 2)
- **Modern Web Development** (Task 3)
- **Full-stack Data Science / MLOps** (Task 4)
- **Optimization / Operations Research** (Task 5)
- **Professional Presentation & Documentation**

## 🎯 Project Goals

✅ Learn industry-standard data preprocessing pipelines  
✅ Develop and train deep learning models  
✅ Create professional interactive web applications  
✅ Master Git version control and GitHub collaboration  
✅ Develop presentation and communication skills

## 🚀 Quick Start

### Prerequisites
- Python 3.8+ (for Tasks 1 & 2)
- Modern web browser (for Task 3)
- pip or conda package manager

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/deimon999/DataScienceInternship.git
   cd DataScienceInternship
   ```

2. **For Task 1 & 2: Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **For Task 3: Open in browser**
   ```bash
   cd Task-3-E-Commerce-Product-Page
   # Open product_page.html in your web browser
   ```

## 📝 Task Descriptions

### Task 1: ETL Pipeline Development
**Objective:** Build a data preprocessing pipeline using pandas and scikit-learn

**Key Features:**
- Data cleaning and duplicate removal
- Missing value imputation
- Feature scaling and encoding
- Automated data transformation

**Technologies:** Python, pandas, scikit-learn

[Read Full Task 1 Documentation](Task-1-ETL-Pipeline/README.md)

---

### Task 2: Deep Learning - CNN Image Classification
**Objective:** Build a CNN model to classify MNIST handwritten digits

**Key Features:**
- Convolutional neural network architecture
- Model training and evaluation
- Performance visualization
- Accuracy metrics and confusion matrix

**Technologies:** Python, TensorFlow, Keras, Matplotlib, NumPy

[Read Full Task 2 Documentation](Task-2-Deep-Learning/README.md)

---

### Task 3: E-Commerce Product Page Design
**Objective:** Create an interactive, professional product page for an e-commerce platform

**Key Features:**
- Interactive 360° product image gallery
- Customer reviews and ratings system
- Product color and warranty selection
- Responsive design (mobile, tablet, desktop)
- Add to cart and wishlist functionality

**Technologies:** HTML5, CSS3, JavaScript (Vanilla)

[Read Full Task 3 Documentation](Task-3-E-Commerce-Product-Page/README.md)
